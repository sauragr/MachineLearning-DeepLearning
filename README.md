# Machine Learning & Deep Learning

This repository contains a collection of Jupyter Notebook-based experiments, implementations, and learning exercises covering fundamental and advanced topics in machine learning, deep learning, and generative AI.

The goal of this project is to provide hands-on examples for understanding key concepts through code-based experimentation and model building.

## Overview

This repository includes notebooks for:

- Linear regression
- Decision trees
- Neural networks
- Convolutional neural networks (CNN)
- Residual networks (ResNet)
- Unsupervised learning
- Generative AI / LLM concepts
- Image-based experimentation
- Data analysis and SQL exploration

Each notebook is designed to help practice and understand machine learning concepts through real examples and model training workflows.

## Repository Contents

- `LinearRegression.ipynb` — implementation and exploration of linear regression
- `DecisionTrees.ipynb` — decision tree learning and classification/regression examples
- `CNN.ipynb` — convolutional neural networks
- `NeuralNetwork.ipynb` — foundational neural network concepts
- `NeuralNetworks.ipynb` — additional neural network experiments
- `Resnets.ipynb` — residual networks and deep learning architecture
- `unsupervisedlearning.ipynb` — clustering and unsupervised learning techniques
- `GENERATIVEai.ipynb` — generative AI concepts and experiments
- `Generative AI with LLM.ipynb` — large language model-focused notebook
- `llmscartch.ipynb` — LLM-related study or experimentation
- `anime_faces.ipynb` and `animefaces.ipynb` — image generation / anime-style exploration
- `layoff_project.sql` — SQL script related to a data project
- `helloworld.md` — introductory or learning note
- `README.md` — project documentation
